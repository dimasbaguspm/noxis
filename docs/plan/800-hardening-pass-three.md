# [plan] Hardening pass three: a tree shaped like the product

Plan issue [#800](https://github.com/dimasbaguspm/noxis/issues/800). Seven tickets, seven pull requests, one green CI. Closed 2026-11-21.

## The problem this solved
The tree had grown seven small lies: a transport under `internal/` that called itself "not a library", thirteen files in `package main` with no shape, an OpenAPI document a human maintained beside the handlers that answer it, route paths in `constants` with one reader, a console that assumed it was on the same machine as the API, a lint policy that was one alphabetical list, SQL that was classified but never proven parameterised, and test doubles re-typed from every interface by hand.

## Where it bent
1. **The transport moved under `cmd/`, and the arch test was the reason it stayed honest.** The first attempt wired the adapters inside `cmd/noxis/http`; `TestImportDirection` refused it. `http.Builder` is the answer: the composition root is still one file in `cmd/noxis`.
2. **`make cover` failed after the move, and the floor was not lowered.** Untested code moved into tested packages, so `serve_test.go` and `wiring_test.go` were written instead: the floors went **up** (`cmd/noxis` 61→67, `cmd/noxis/http` 54→74, `internal/web` 75→77, `sqltext` 73→74, `proposal` 82→83), and two new floors were added (`cmd/noxis/commands` 8, `http/middlewares` 18).
3. **The generated document does not carry scopes, and its payloads stop at the envelope.** swag v2 drops custom extensions, and the wire views are still unexported. Both halves are filed as [#815](https://github.com/dimasbaguspm/noxis/issues/815) rather than pretended away — the contract test proves paths, methods and security in both directions, which is what it can prove today.
4. **A block is a proposal, not a permission.** MySQL and MariaDB refuse `BEGIN … END` outside a procedure body; the UAT scenario asserts the proposal is accepted (201) and the rehearsal verdict is the engine's (`failed`), not a refusal from our own guard.
